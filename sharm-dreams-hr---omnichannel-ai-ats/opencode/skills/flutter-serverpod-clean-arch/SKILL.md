# Flutter + Serverpod Clean Architecture Skill

## Core Principles

1. **Separation of Concerns:**
   - **Domain Layer:** Pure Dart. Zero dependencies on Flutter UI or Serverpod SDK. Contains Entities, Use Cases (Interactors), and Repository Interfaces.
   - **Data Layer:** Implements Repository Interfaces. Contains Data Sources (Serverpod Client RPCs, Local Cache), DTOs / Mappers, and Serverpod Model adapters.
   - **Presentation Layer:** Flutter UI with `flutter_bloc`. BLoCs handle state transformations; Widgets are purely declarative and reactive.

2. **Serverpod Backend Architecture:**
   - Define data models in `server/lib/src/models/*.spy.yaml`.
   - Run `serverpod generate` to generate serialization, database tables, and client code.
   - Write business logic in `server/lib/src/endpoints/*_endpoint.dart`.
   - Use Serverpod ORM for PostgreSQL queries, transactions, and authentication scopes.

3. **Routing & Navigation:**
   - Use `go_router` for all navigation.
   - Configure clean, dynamic web URLs with `usePathUrlStrategy()` from `flutter_web_plugins/url_strategy.dart`.
   - Implement route guards, redirection logic for auth states, and typed route parameters.

4. **State Management with BLoC:**
   - Use Freezed or sealed classes for BLoC Events and States.
   - Distinct states: `Initial`, `Loading`, `Success`, `Failure(error, message)`.
   - Handle concurrency with custom event transformers (`droppable()`, `restartable()`) from `bloc_concurrency`.

## Step-by-Step Implementation Recipes

### 1. Flutter Web Clean Path URL Strategy (`main.dart`)
Never use hash fragments (`/#/`) in web production URLs.

```dart
// lib/main.dart
import 'package:flutter/material.dart';
import 'package:flutter_web_plugins/url_strategy.dart';
import 'package:my_app_flutter/core/network/serverpod_client.dart';
import 'package:my_app_flutter/core/router/app_router.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // Dynamic Clean Path URL Strategy (Removes # from URLs)
  usePathUrlStrategy();

  // Initialize Serverpod Client
  await initializeServerpodClient();

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp.router(
      title: 'Enterprise App',
      debugShowCheckedModeBanner: false,
      routerConfig: appRouter,
      theme: ThemeData(
        useMaterial3: true,
        colorSchemeSeed: Colors.amber,
      ),
    );
  }
}
```

### 2. Declarative `go_router` with Auth Guards
```dart
// lib/core/router/app_router.dart
import 'package:flutter/material.dart';
import 'package:go_router/go_router.dart';
import 'package:my_app_flutter/features/auth/presentation/pages/login_page.dart';
import 'package:my_app_flutter/features/recruitment/presentation/pages/candidate_list_page.dart';
import 'package:my_app_flutter/features/recruitment/presentation/pages/candidate_detail_page.dart';

final GlobalKey<NavigatorState> _rootNavigatorKey = GlobalKey<NavigatorState>();

final GoRouter appRouter = GoRouter(
  navigatorKey: _rootNavigatorKey,
  initialLocation: '/candidates',
  routes: [
    GoRoute(
      path: '/login',
      name: 'login',
      builder: (context, state) => const LoginPage(),
    ),
    GoRoute(
      path: '/candidates',
      name: 'candidates',
      builder: (context, state) => const CandidateListPage(),
      routes: [
        GoRoute(
          path: ':id',
          name: 'candidate-detail',
          builder: (context, state) {
            final id = state.pathParameters['id']!;
            return CandidateDetailPage(candidateId: id);
          },
        ),
      ],
    ),
  ],
  redirect: (context, state) {
    // Inject auth checks here
    return null;
  },
);
```

### 4. Serverpod Endpoint (`candidate_endpoint.dart`)
```dart
// my_app_server/lib/src/endpoints/candidate_endpoint.dart
import 'package:serverpod/serverpod.dart';
import '../generated/protocol.dart';

class CandidateEndpoint extends Endpoint {
  Future<List<Candidate>> getCandidates(
    Session session, {
    String? sector,
  }) async {
    final where = sector != null && sector.isNotEmpty
        ? (t) => t.sector.equals(sector)
        : null;

    return await Candidate.db.find(
      session,
      where: where,
      orderBy: (t) => t.createdAt,
      orderDescending: true,
    );
  }

  Future<Candidate> createCandidate(
    Session session,
    Candidate candidate,
  ) async {
    return await Candidate.db.insertRow(session, candidate);
  }

  Future<Candidate?> evaluateCandidate(
    Session session,
    int candidateId,
  ) async {
    final candidate = await Candidate.db.findById(session, candidateId);
    if (candidate == null) return null;

    // Run business logic or AI scoring
    candidate.aiFitScore = 88;
    candidate.aiSummary = 'Candidate evaluated via Serverpod endpoint';
    candidate.status = 'AI Screened';

    return await Candidate.db.updateRow(session, candidate);
  }
}
```

### 5. Flutter BLoC Pattern (`candidate_bloc.dart`)
```dart
// lib/features/recruitment/presentation/bloc/candidate_bloc.dart
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:equatable/equatable.dart';
import '../../domain/entities/candidate_entity.dart';
import '../../domain/usecases/get_candidates_usecase.dart';

// Events
abstract class CandidateEvent extends Equatable {
  const CandidateEvent();
  @override
  List<Object?> get props => [];
}

class LoadCandidatesEvent extends CandidateEvent {
  final String? sectorFilter;
  const LoadCandidatesEvent({this.sectorFilter});
  @override
  List<Object?> get props => [sectorFilter];
}

// States
abstract class CandidateState extends Equatable {
  const CandidateState();
  @override
  List<Object?> get props => [];
}

class CandidateInitial extends CandidateState {}
class CandidateLoading extends CandidateState {}
class CandidateLoaded extends CandidateState {
  final List<CandidateEntity> candidates;
  const CandidateLoaded(this.candidates);
  @override
  List<Object?> get props => [candidates];
}
class CandidateError extends CandidateState {
  final String message;
  const CandidateError(this.message);
  @override
  List<Object?> get props => [message];
}

// Bloc
class CandidateBloc extends Bloc<CandidateEvent, CandidateState> {
  final GetCandidatesUseCase getCandidatesUseCase;

  CandidateBloc({required this.getCandidatesUseCase}) : super(CandidateInitial()) {
    on<LoadCandidatesEvent>((event, emit) async {
      emit(CandidateLoading());
      final result = await getCandidatesUseCase(event.sectorFilter);
      result.fold(
        (failure) => emit(CandidateError(failure.message)),
        (candidates) => emit(CandidateLoaded(candidates)),
      );
    });
  }
}
```

## Verification & Execution Commands

```bash
# 1. Generate Serverpod code and DB migrations:
cd my_app_server
serverpod generate
serverpod create-migration

# 2. Run Serverpod local Postgres and Server:
docker compose up -d
dart bin/main.dart --apply-migrations

# 3. Run Flutter client:
cd ../my_app_flutter
flutter pub get
flutter run -d chrome
```
